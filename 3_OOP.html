Object Oriented Programming

1 Classes

1.1 Why classes?

In the previous chapters, we wrote functions to scrape university restaurant menus. Each function does one thing: get a page, extract a date, parse meals, etc. This works fine, but as our code grows, we face some issues:

  • We pass the same arguments (like driver) to many functions.
  • Our data is stored in deeply nested dictionaries that are hard to read and maintain.
  • If someone new reads the code, they have to understand all the functions and how they connect.

A class groups related data and functions together into a single object.

1.2 Scope and Namespaces

It’s important to understand how Python finds variables. Python uses the LEGB rule:

  1. Local: inside the current function
  2. Enclosing: inside any parent function (for nested functions)
  3. Global: at the module/file level
  4. Built-in: Python’s built-in names (print, len, etc.)
x = "global"

def my_function():
    x = "local"
    print(x)  # prints "local" (found in Local first)

my_function()
## local
print(x)  # prints "global"
## global

A more complete example showing nonlocal and global:

def scope_test():
    def do_local():
        spam = "local spam"

    def do_nonlocal():
        nonlocal spam
        spam = "nonlocal spam"

    def do_global():
        global spam
        spam = "global spam"

    spam = "test spam"
    do_local()
    print("After local assignment:", spam)
    do_nonlocal()
    print("After nonlocal assignment:", spam)
    do_global()
    print("After global assignment:", spam)

scope_test()
## After local assignment: test spam
## After nonlocal assignment: nonlocal spam
## After global assignment: nonlocal spam
print("In global scope:", spam)
## In global scope: global spam

1.3 Defining a class

The simplest form of a class definition:

class ClassName:
    <statement-1>
    ...
    <statement-N>

A class supports two kinds of operations: attribute references (accessing names with a dot: obj.name) and instantiation (creating a new object from the class).

Let’s start with a simple example related to our scraper. Imagine we want to represent a restaurant:

class Restaurant:
    """A simple class to represent a restaurant"""
    base_url = 'https://www.crous-strasbourg.fr'

    def full_url(self):
        return self.base_url + '/se-restaurer/'

# Attribute references
Restaurant.base_url
## 'https://www.crous-strasbourg.fr'

# Instantiation
r = Restaurant()

r.full_url()
## 'https://www.crous-strasbourg.fr/se-restaurer/'
r.base_url
## 'https://www.crous-strasbourg.fr'

self is the instance itself. When you call r.full_url(), Python automatically passes r as the first argument. So r.full_url() is equivalent to Restaurant.full_url(r).

1.4 The __init__ method

Most classes need to set up an initial state when they are created. This is done with the special method __init__(), which is called automatically when you create a new instance.

class Restaurant:
    def __init__(self, name, url):
        self.name = name
        self.url = url

r = Restaurant('Resto U Esplanade', 'https://www.crous-strasbourg.fr/restaurant/resto-u-esplanade/')
r.name
## 'Resto U Esplanade'
r.url
## 'https://www.crous-strasbourg.fr/restaurant/resto-u-esplanade/'

1.5 Class variables vs instance variables

Class variables are shared by all instances. Instance variables are unique to each instance.

class Restaurant:
    source = 'CROUS Strasbourg'   # class variable shared by all instances

    def __init__(self, name, url):
        self.name = name          # instance variable unique to each instance
        self.url = url

r1 = Restaurant('Esplanade', '/restaurant/resto-u-esplanade/')
r2 = Restaurant('Paul Appell', '/restaurant/resto-u-paul-appell/')

r1.source   
## 'CROUS Strasbourg'
r2.source   
## 'CROUS Strasbourg'

r1.name   
## 'Esplanade'
r2.name     
## 'Paul Appell'

Careful with mutable class variables! A list defined as a class variable is shared by all instances, which can lead to unexpected behavior:

# WRONG
class Restaurant:
    menus = [] # shared by ALL restaurants!

    def __init__(self, name):
        self.name = name

    def add_menu(self, menu):
        self.menus.append(menu)

r1 = Restaurant('Esplanade')
r2 = Restaurant('Paul Appell')

r1.add_menu('Lundi: Lasagne')
r2.add_menu('Lundi: Poulet')

r1.menus   
## ['Lundi: Lasagne', 'Lundi: Poulet']
# CORRECT
class Restaurant:
    def __init__(self, name):
        self.name = name
        self.menus = [] # new list for each restaurant

    def add_menu(self, menu):
        self.menus.append(menu)

r1 = Restaurant('Esplanade')
r2 = Restaurant('Paul Appell')

r1.add_menu('Lundi: Lasagne')
r2.add_menu('Lundi: Poulet')

r1.menus    
## ['Lundi: Lasagne']
r2.menus    
## ['Lundi: Poulet']

This distinction will matter when we build our scraper class. For instance, USER_AGENT and BASE_URL are the same for every scraper instance — they should be class variables. But driver (the browser window) must be unique to each instance — it must be an instance variable. If driver were a class variable, all scraper instances would share the same browser window. If one calls close(), the other would break.

1.6 Methods calling other methods

Inside a class, methods can call other methods using self:

class Restaurant:
    def __init__(self, name):
        self.name = name
        self.menus = []

    def add_menu(self, menu):
        self.menus.append(menu)

    def add_week_menus(self, weekly_menus):
        for menu in weekly_menus:
            self.add_menu(menu)

r = Restaurant('Esplanade')
r.add_week_menus(['Lundi: Lasagne', 'Mardi: Poulet', 'Mercredi: Poisson'])
r.menus  
## ['Lundi: Lasagne', 'Mardi: Poulet', 'Mercredi: Poisson']

2.1 Our functional code

In the Selenium chapter, we wrote these functions to scrape restaurant menus:

    for menu in menus:
        date = get_date(menu)
        meals = driver.find_elements(By.CLASS_NAME,'meal')

                resto_u_all_infos[date][name][meal_type].update({pole:meal_infos})

def get_all_infos():

    links = get_all_links(driver)
    all_resto_u_all_infos = dict()
    for name, link in links.items():

    driver.quit()
    return all_resto_u_all_infos

We pass driver to almost every function. It’s a shared resource that all functions need. The user_agent and BASE_URL are global variables floating around. If we want to add new features (e.g., search for a dish), we write yet another standalone function that needs the whole nested dictionary passed to it.

2.2 Wrapping functions into a class

We take all the functions and the shared state (driver, user_agent, BASE_URL) and put them together inside a class. The driver that was passed around becomes self.driver.

from selenium import webdriver
from selenium.webdriver.firefox.options import Options  
from selenium.webdriver.common.by import By
import time
import random
import re

3 Going further

3.1 Improving the design

V1 is a direct translation from functions to a class. It works, but we can do better. Here are the improvements we’ll make:

  • Use private methods: prefix internal helpers with _ to separate what’s public from what’s internal.
  • Use data classes: instead of nested dictionaries, create proper objects to hold our data.

Python does not have truly private variables. However, the convention is to prefix internal names with an underscore _.

class CrousScraper:
    def get_all_infos(self): # public: meant to be called by the user
        pass
    
    def _get_date(self, menu): # private: internal helper
        pass

3.2 Dataclasses

A dataclass is a shortcut for creating classes that mainly store data. Instead of writing __init__, __repr__, and __eq__ yourself, the @dataclass decorator generates them automatically.

from dataclasses import dataclass

# Without dataclass
class Restaurant:
    def __init__(self, name, url):
        self.name = name
        self.url = url
    
    def __repr__(self):
        return f"Restaurant(name={self.name}, url={self.url})"

# With dataclass
@dataclass
class Restaurant:
    name: str
    url: str
r = Restaurant('Resto U Esplanade', 'https://www.crous-strasbourg.fr/restaurant/resto-u-esplanade/')
r.name
## 'Resto U Esplanade'
r.url
## 'https://www.crous-strasbourg.fr/restaurant/resto-u-esplanade/'
print(r)
## Restaurant(name='Resto U Esplanade', url='https://www.crous-strasbourg.fr/restaurant/resto-u-esplanade/')

For our scraper, we can define data classes to hold the structured menu data:

from dataclasses import dataclass, field

@dataclass
class Restaurant:
    name: str
    url: str

@dataclass
class Menu:
    date: str
    meals: dict = field(default_factory=dict)
    # Structure : {meal_type: {pole: [meal]}}
    
    def add_meal(self, meal_type, pole, meal):
        if meal_type not in self.meals:
            self.meals[meal_type] = {}
        self.meals[meal_type][pole] = meal

@dataclass
class MenuCollection:
    data: dict = field(default_factory=dict)
    # Structure : {date: {restaurant_name: Menu}}
    
    def add_menu(self, date, restaurant_name, menu):
        if date not in self.data:
            self.data[date] = {}
        self.data[date][restaurant_name] = menu
    
    def get_dates(self):
        return list(self.data.keys())
    
    def get_restaurants(self, date):
        return list(self.data[date].keys())

The use of field(default_factory=dict) avoids the mutable class variable trap we saw earlier with the Restaurant.menus example. Each instance gets its own fresh dictionary.

3.3 Scraper (V2)

from selenium import webdriver
from selenium.webdriver.firefox.options import Options  
from selenium.webdriver.common.by import By
import time
import random
import re

class CrousScraper:
    
    USER_AGENT = 'Mozilla/5.0 (Macintosh; Intel Mac OS X 10.15; rv:147.0) Gecko/20100101 Firefox/147.0'
    BASE_URL = 'https://www.crous-strasbourg.fr/se-restaurer/ou-manger/'
    
    def __init__(self):
        self.driver = None
        self._init_driver()
    
    def _init_driver(self):
        firefox_options = Options()
        firefox_options.set_preference("general.useragent.override", self.USER_AGENT)
        firefox_options.add_argument("--headless")
        self.driver = webdriver.Firefox(options=firefox_options)
    
    
    def close(self):
        if self.driver:
            self.driver.quit()
            self.driver = None
    
    def get_all_restaurants_links(self):
        self.driver.get(self.BASE_URL)
        elements = self.driver.find_elements(By.CSS_SELECTOR, 'li a')
        
        restaurants = []
        for element in elements:
            link = element.get_attribute("href")
            if link and '/restaurant/' in link:
                name = self._get_restaurant_name(link)
                restaurants.append(Restaurant(name, link))
        return restaurants
    
    def _get_restaurant_name(self, link):
        name = re.findall('restaurant/(.*)/', link)[0]
        name = re.sub('-', ' ', name)
        name = re.sub(' 2', '', name)
        return name.title()
    
    def _get_page(self, url):
        time.sleep(2 + random.uniform(0, 8))
        self.driver.get(url)
    
    def get_all_meals_from_resto_u(self, restaurant):
        self._get_page(restaurant.url)
        menu_elements = self.driver.find_elements(By.CLASS_NAME, 'menu')
        
        menu_collection = MenuCollection()
        for menu_elem in menu_elements:
            date = self._get_date(menu_elem)
            menu = Menu(date)
            
            meal_elements = menu_elem.find_elements(By.CLASS_NAME, 'meal')
            for meal_elem in meal_elements:
                meal_type, pole_elements = self._get_meal_type_and_poles(meal_elem)
                for pole_elem in pole_elements:
                    pole, meal = self._get_meal_infos(pole_elem)
                    menu.add_meal(meal_type, pole, meal)
            
            menu_collection.add_menu(date, restaurant.name, menu)
        return menu_collection
    
    def _get_date(self, menu_elem):
        date_elem = menu_elem.find_element(By.CLASS_NAME, 'menu_date_title')
        return re.sub('Menu du ', '', date_elem.text)
    
    def _get_meal_type_and_poles(self, meal_elem):
        meal_type = meal_elem.find_element(By.CLASS_NAME, "meal_title").text
        pole_elements = meal_elem.find_elements(By.CSS_SELECTOR, 'ul.meal_foodies > li')
        return meal_type, pole_elements
    
    def _get_meal_infos(self, pole_elem):
        pole_html = pole_elem.get_attribute('innerHTML')
        pole, meal_infos = pole_html.split("<ul><li>")
        meal_infos = meal_infos.split('</li><li>')
        meal_infos = [re.sub('</li></ul>','',meal) for meal in meal_infos if meal != '-']
        return pole, meal_infos
    
    def get_all_infos(self):
        restaurants = self.get_all_links()
        all_menus = MenuCollection()
        for restaurant in restaurants:
            resto_menus = self.get_all_meals_from_resto_u(restaurant)
            for date in resto_menus.data.keys():
                for resto_name, menu in resto_menus.data[date].items():
                    all_menus.add_menu(date, resto_name, menu)
        return all_menus

4 Inheritance

Python supports inheritance: a class can be built on top of another class, reusing and extending its code. The syntax is:

class DerivedClassName(BaseClassName):
    ...

The derived class inherits all methods and attributes from the base class. It can then override existing methods (replace them with new behavior) or add new methods. The super() function lets you call methods from the base class.

Let’s say we want to factor out the generic scraping logic (driver management, page navigation) from the specific CROUS logic (parsing menus, extracting dates). We can create a base class:

class BaseScraper:
  
    USER_AGENT = 'Mozilla/5.0 (Macintosh; Intel Mac OS X 10.15; rv:147.0) Gecko/20100101 Firefox/147.0'
    
    def __init__(self):
        self.driver = None
    
    def _init_driver(self):
        firefox_options = Options()
        firefox_options.set_preference("general.useragent.override", self.USER_AGENT)
        firefox_options.add_argument("--headless")
        self.driver = webdriver.Firefox(options=firefox_options)
    
    def _get_page(self, url):
        time.sleep(2 + random.uniform(0, 8))
        self.driver.get(url)
    
    def close(self):
        if self.driver:
            self.driver.quit()
            self.driver = None

BaseScraper contains all the logic that is common to any scraping task: managing the driver, navigating to a page, closing the browser.

Now we can create specialized scrapers that inherit from BaseScraper. Each one gets _init_driver(), _get_page(), and close() for free, and only needs to implement its own scrape():

class CrousScraper(BaseScraper):
    
    BASE_URL = 'https://www.crous-strasbourg.fr/se-restaurer/ou-manger/'
    
    def __init__(self):
        # super().__init__() calls BaseScraper.__init__()
        super().__init__()
        self._init_driver()  # inherited from BaseScraper
    
    def get_all_restaurants_links(self):
        self.driver.get(self.BASE_URL)
        elements = self.driver.find_elements(By.CSS_SELECTOR, 'li a')
        
        restaurants = []
        for element in elements:
            link = element.get_attribute("href")
            if link and '/restaurant/' in link:
                name = self._get_restaurant_name(link)
                restaurants.append(Restaurant(name, link))
        return restaurants
    
    def _get_restaurant_name(self, link):
        name = re.findall('restaurant/(.*)/', link)[0]
        name = re.sub('-', ' ', name)
        name = re.sub(' 2', '', name)
        return name.title()
    
    def get_all_meals_from_resto_u(self, restaurant):
        self._get_page(restaurant.url)
        menu_elements = self.driver.find_elements(By.CLASS_NAME, 'menu')
        
        menu_collection = MenuCollection()
        for menu_elem in menu_elements:
            date = self._get_date(menu_elem)
            menu = Menu(date)
            
            meal_elements = menu_elem.find_elements(By.CLASS_NAME, 'meal')
            for meal_elem in meal_elements:
                meal_type, pole_elements = self._get_meal_type_and_poles(meal_elem)
                for pole_elem in pole_elements:
                    pole, meal = self._get_meal_infos(pole_elem)
                    menu.add_meal(meal_type, pole, meal)
            
            menu_collection.add_menu(date, restaurant.name, menu)
        return menu_collection
    
    def _get_date(self, menu_elem):
        date_elem = menu_elem.find_element(By.CLASS_NAME, 'menu_date_title')
        return re.sub('Menu du ', '', date_elem.text)
    
    def _get_meal_type_and_poles(self, meal_elem):
        meal_type = meal_elem.find_element(By.CLASS_NAME, "meal_title").text
        pole_elements = meal_elem.find_elements(By.CSS_SELECTOR, 'ul.meal_foodies > li')
        return meal_type, pole_elements
    
    def _get_meal_infos(self, pole_elem):
        pole_html = pole_elem.get_attribute('innerHTML')
        pole, meal_infos = pole_html.split("<ul><li>")
        meal_infos = meal_infos.split('</li><li>')
        meal_infos = [re.sub('</li></ul>','',meal) for meal in meal_infos if meal != '-']
        return pole, meal_infos
    
    def get_all_infos(self):
        restaurants = self.get_all_links()
        all_menus = MenuCollection()
        for restaurant in restaurants:
            resto_menus = self.get_all_meals_from_resto_u(restaurant)
            for date in resto_menus.data.keys():
                for resto_name, menu in resto_menus.data[date].items():
                    all_menus.add_menu(date, resto_name, menu)
        return all_menus
