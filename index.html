1 Description

  • This course is part of the second semester of M1 DS2E/SE. It aims at providing students with advanced programming concepts including regular expressions, web scraping, API interaction, object-oriented programming, error handling, and parallel computing using Python.

 

  • Each session will be divided into two parts, first we will go through the course using this site as a support. In the second part of the course students will be asked to solve exercises and present their approaches to others. The aim is to familiarize students with presenting and explaining their codes, but it is even more important that it serves students to benchmark their different approaches in order to better understand how to improve their code.

 

This lecture is structured as follows :

  • Chapter ‘Regex’ gives an overview of regular expressions and string manipulation for text processing and data extraction.

     

  • Chapter ‘Web Scraping’ covers web scraping techniques using Selenium.

     

  • Chapter ‘Object-Oriented Programming’ introduces classes, methods, and object-oriented design principles in Python for building reusable and maintainable tools.

     

  • Chapter ‘Efficient Programming’ is an introduction to parallel computing, error handling, debugging strategies, and code optimization. Its benefits and limitations will be discussed.

 

2 Exams

There are two different grades in this course :

  • A written exam ON PAPER with no computer access (03/03/2026).

     

  • A project to be handed in by groups of 2-3 students, to be submitted by 01/03/2026 and presented orally on 02/03/2026.

    Project Overview: Automated Web Scraping Tool

    Create a fully automated tool that collects and processes data from a website of your choice. The tool must be able to run without manual intervention and extract structured information from web pages.

    Key Requirements:

    • Web Scraping: The project MUST involve web scraping as its core functionality.
    • Automation: The tool must be fully automated - it should collect data without requiring manual steps.
    • Website Choice: You are free to choose any website, but consider:
      • Legal aspects (respect robots.txt, terms of service)
      • Technical feasibility (static vs dynamic content)
      • Data availability and consistency
      • Rate limiting and ethical scraping practices
    • Tool Development: Build a reusable tool that others could use or adapt for similar tasks.
    • GitHub Publication: The complete project must be published on GitHub.

    GitHub Requirements:

    • Clean README.md file including:
      • Project description and purpose
      • Installation instructions
      • Usage examples
      • Dependencies list
      • Legal disclaimer (if applicable)
    • Clear project structure:
      • Organized folder hierarchy
      • Separation of data, scripts, and documentation
      • Proper .gitignore file (exclude data files, credentials, cache)
    • Well-documented code with comments
    • Requirements.txt file

    Critical Reminders: Ethics & Legality

    • Always respect robots.txt files
    • Implement appropriate delays between requests
    • Do not overwhelm servers with requests
    • Check website terms of service
    • Consider using official APIs when available
    • Store credentials securely (never commit them to Git)
    • Be transparent about data collection in your README
    • Use Selenium responsibly (headless mode when possible, appropriate wait times)

 

  • The oral presentation (02/03/2026) will focus on:
    • Demonstration of the tool’s functionality
    • Discussion of technical challenges and solutions
    • Explanation of code architecture and design choices
    • Web scraping strategies and ethical considerations
    • Strengths and limitations of the implementation
    • Potential improvements and future developments
